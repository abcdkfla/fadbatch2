# Fed-Batch Lab · 운전 설계

C. glutamicum 운전 조건을 비교하는 교육용 브라우저 시뮬레이터입니다. 실측 예측이나 실물 장비 제어용이 아닙니다.

## 실행 및 GitHub Pages

- 서버나 설치 없이 `index.html`을 브라우저에서 열면 실행됩니다. 원본 프로젝트에서 파일은 `dist/`에 있습니다.
- GitHub용 ZIP은 압축을 풀고 그 안의 파일들을 저장소 **최상위**에 올리세요. ZIP 자체를 올리면 웹페이지가 열리지 않습니다.
- 저장소 Settings → Pages에서 브랜치 배포를 선택하고, 올린 브랜치(보통 `main`)의 `/ (root)`를 선택하세요.

## 모델 범위

입력: 목표 μ, rpm, 초기 부피, 통기량(0.5 / 1 / 2 vvm), 공급액 글루코스 농도(기본 100, 최대 800 g/L), 공급 개시 기준(1–5 g/L). 공급액은 5 g/L보다 높아야 하며 혼합 직후 배양기 내부는 50 g/L 이하로 제한합니다.

초기 글루코스는 10 g/L. 실행 전에 고른 공급액 농도는 종료까지 모든 투입에 동일하게 적용합니다. 잔류 글루코스가 선택 기준 이하이면 공급하고, 초과하면 멈췄다가 다시 내려오면 재개합니다. 24시간 또는 2.5 L 도달 중 먼저 발생한 시점에 종료하며, 30분 간격 기록과 실제 종료 시각을 제공합니다.

수율 비교 지표는 순증가 균체량/소비 글루코스입니다. 산소는 첨부 자료의 단일 계수 12 mmol/g 근사입니다. 공기 유량(L/min)은 선택 vvm × 현재 배양 부피(L)입니다. 순산소·자동 DO 제어는 포함하지 않습니다. DO는 정상상태 근사, 초기 OD600 0.20은 기존 모델 가정이며, DCW 환산은 본 장비에서 검증되지 않았습니다.
